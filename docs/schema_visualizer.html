Inter-Service Lineages & Documented Interfaces

To remain completely compliant with ADR-2164 and prevent runtime database cross-dependencies, standard microservices in the Cadence platform are structurally isolated. Sibling microservices cannot directly query each other's storage backends. Instead, all cross-service boundaries communicate exclusively through secure, pre-defined, and authenticated REST APIs and Events.

Designer → Execution USDM Ingestion

The Execution Service statically imports clinical protocol structures designed within the Neo4j Graph database. Relies on the /api/v1/designer/usdm/export endpoint with HMAC signoffs, guaranteeing strict non-repudiation.

Execution → eTMF Filing & Archival

Clinical documentation, subject consents, and electronic signatures are captured in the relational EDC model, then pushed to the eTMF repository. Communication requires GatewayAuthMiddleware verification.

System → Ledger HMAC Auditing

All GxP audited models hook into the Part11AuditMixin and AuditFields. Standard transactions are cryptographically signed and chained in a SHA-256 HMAC ledger, satisfying Part 11 electronic records.
