# Multi-Channel Notifications Dispatcher

> **Functional Domain:** `Patient Engagement & Interoperability`  
> **Service Host Port:** `localhost:8010`  
> **Gateway Proxy Prefix:** `/api/v1/notifications`  
> **Persistence Backend:** `PostgreSQL / SQLite`  

## Overview

Automated patient compliance reminders and high-priority GxP alerts across SMTP Email (Jinja2), SMS, HMAC Webhooks, and In-App inbox.

---

| Method | Path | Summary | GxP Auth & Signatures |
| :--- | :--- | :--- | :--- |

## Granular Endpoint Specifications

### `POST` `/api/v1/notifications`

**Summary:** Create Notification  
**Operation ID:** `create_notification_api_v1_notifications_post`  

**Clinical & GxP Rationale:**  
Create a new notification targeting a specific user ID or role.

#### Security & Access Control (21 CFR Part 11)

- **Authentication:** OIDC Bearer Token (Keycloak)
- **Gateway Headers:** Verified `X-Gateway-Signature` (HMAC-SHA256)
- **Step-Up Electronic Signature:** Required if mutating locked records

#### Request Payload Schema (`application/json`)

**Schema Type:** `NotificationCreate`

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `recipient_user_id` | `string` | `null` | No | Optional target user ID |
| `recipient_role` | `string` | `null` | No | Optional target role |
| `category` | `NotificationCategory` | ✔ Yes | Category: ALERTS, SYSTEM, ACTION_ITEMS |
| `priority` | `NotificationPriority` | ✔ Yes | Priority: LOW, MEDIUM, HIGH, CRITICAL |
| `channels` | `string` | No | Comma-separated delivery channels (e.g. 'IN_APP,EMAIL') |
| `message_content` | `string` | ✔ Yes | Message content |
| `related_entity_id` | `string` | `null` | No | Optional related entity ID |
| `related_entity_type` | `string` | `null` | No | Optional related entity type |

#### Response Codes & Schemas

| HTTP Status | Description | Response Schema |
| :--- | :--- | :--- |
| `201` | Successful Response | `NotificationResponse` |
| `422` | Validation Error | `HTTPValidationError` |

#### Client Code Examples

::: code-group
```typescript [TypeScript (Fetch)]
const response = await fetch('http://localhost:8000/api/v1/notifications/api/v1/notifications', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${userToken}`,
    'Content-Type': 'application/json',
    'X-Change-Reason': 'Clinical routine data capture',
  },
  body: JSON.stringify(payload),
});
const data = await response.json();
```

```python [Python (HTTPX)]

        '/api/v1/notifications/api/v1/notifications',
        headers={
            'Authorization': f'Bearer {user_token}',
            'X-Change-Reason': 'Clinical routine data capture',
        },
        json=payload,

```

