# Environment Variables

Every configuration key the .NET services, CLI and web apps read, with where it is read. The template with local
defaults is [`.env.example`](../.env.example). `cadence check` warns when code reads an environment variable that
`.env.example` does not list, and when `.env.example` lists a key this page does not.

ASP.NET Core services read these through `IConfiguration`, so environment variables, `appsettings*.json` and
command-line arguments all work; `__` in an environment variable name maps to `:` (for example
`ConnectionStrings__cadence` is `ConnectionStrings:cadence`). CLI and library code that calls
`Environment.GetEnvironmentVariable` reads the process environment only.

"Required" means the service (or tool) fails with an error naming the key when it is unset. There are no built-in
fallback credentials in any environment, Development included (ADR-2260).

## Field-level protection

Keys for `packages/security/src/FieldProtection` (#4770). Both are base64 encodings of exactly 32 random bytes
(`openssl rand -base64 32`), are validated when the host starts, and have no default in any environment. Use two
different keys. See [ADR-2494](adr/2026-09-30-field-level-encryption-and-keyed-lookup-hashes-for-secrets-at-rest.md). Under the Aspire AppHost, set them as the
`field-encryption-key` and `field-lookup-hash-key` parameters. Imaging's two de-identification keys are the
`imaging-deid-signing-key` and `imaging-deid-pseudonymization-key` parameters.

| Key                                         | Read by                                                                                                                                                                                          | Default | Required                                                                                                                                                                                                                 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `FIELD_ENCRYPTION_KEY`                      | `packages/security/src/FieldProtection/FieldProtectionServiceCollectionExtensions.cs` (`AddCadenceFieldEncryption`), called by `apps/payments/src/Program.cs` and `apps/econsent/src/Program.cs` | none    | yes (payments, econsent); the service refuses to start without a valid key. Rotating it makes existing ciphertext unreadable                                                                                             |
| `FIELD_LOOKUP_HASH_KEY`                     | same file (`AddCadenceLookupHashing`), called by `apps/interop/src/Program.cs`                                                                                                                   | none    | yes (interop); the service refuses to start without a valid key. Rotating it orphans stored device-token hashes                                                                                                          |
| `CADENCE_SCE_SIGNING_KEY`                   | `apps/interop/src/Infrastructure/Security/SceTokenSigner.cs` (`AddSceSigning`), called by `apps/interop/src/Program.cs`                                                                          | none    | yes (interop); base64 of 32 bytes. The service refuses to start without a valid key. Rotating it invalidates outstanding SCE database-lock tokens (ADR-2515)                                                             |
| `CADENCE_IMAGING_DEID_SIGNING_KEY`          | `apps/imaging/src/Infrastructure/Security/DeidentificationKeys.cs` (`AddImagingDeidentification`), called by `apps/imaging/src/Program.cs`                                                       | none    | yes (imaging); base64 of 32 bytes. | `CADENCE_IMAGING_DEID_PSEUDONYMIZATION_KEY` | same file                                                                                                                                                                                        | none    | yes (imaging); base64 of 32 bytes, different from the signing key.
