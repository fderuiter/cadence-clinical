# Writing: Shape

Transforms an ordered progression of beats into a complete, readable technical document, paragraph by paragraph.

## Rules
- Draft one paragraph per beat.
- Open with clear assertions.
- Use concrete examples and code blocks.
- End with actionable summaries.
