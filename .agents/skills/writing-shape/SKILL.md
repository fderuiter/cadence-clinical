# Writing: Shape

Transforms an ordered progression of beats into a complete, readable technical document, paragraph by paragraph, using Antigravity artifact tools.

## Antigravity Tool Execution Matrix

| Phase                  | Antigravity Tool | Invocation Pattern                                                                   | Objective                                             |
| :--------------------- | :--------------- | :----------------------------------------------------------------------------------- | :---------------------------------------------------- |
| **Document Synthesis** | `write_to_file`  | Target: `<appDataDir>/brain/<conversation-id>/<doc_name>.md` with `ArtifactMetadata` | Emit final polished article or specification document |

---

## Rules

- Draft one paragraph per beat.
- Open with clear assertions.
- Use concrete examples and code blocks.
- End with actionable summaries.
