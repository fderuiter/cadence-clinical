# ui

Shared frontend package (JavaScript, TypeScript types and Vue 3 components) used by the web client and the subject portal.

## Contents

- `index.js` (main entry, built to `dist/` as an ES and CJS library): helpers such as `debounce`, `createSrOnlyActionButton` (accessible DOM button builder appending `.sr-only` context while preserving leading visible verbs per WCAG 2.2 SC 2.5.3), HTML builders for lookup inputs, rule editors and schedule-of-activities matrices, condition-tree serialisation, `initHoverDetection`, and re-exports of the modules and components below.
- `signing.js`: browser-side hashing, canonical serialisation, AES-GCM helpers (`sha256`, `canonicalSerialize`, `encryptAESGCM`, `deriveKeyFromPIN`), and 21 CFR Part 11 v3 step-up helpers (`SEMANTIC_ACTIONS`, `isValidSemanticAction`, `buildStepUpVerificationPayload`, `SIGNATURE_PASSWORD_INPUT_ATTRS`, `requiresCustomSignatureReason`, `resolveSignatureReason`, `deriveSignerRoleFromClaims`).
- `session.js`: shared OIDC session coordinator (`createOidcSessionCoordinator`) providing `onTokenExpired` / `onAuthRefreshSuccess` registration, single-flight `updateToken` deduplication, one-shot `401` refresh-and-retry, draft-preserving involuntary expiry transitions, and safe same-origin return-URL persistence (ADR-2551).
- `mockGateway.js`, exported only as `ui/testing`: the gateway simulator for MSW handlers and tests (`validateGatewayRequest`, `isGatewayApiCall`, `isPathSignatureGated`). It is not part of the root export and holds no secret: it verifies an `X-Gateway-Signature` only against a secret the caller passes as `options.secret`, and rejects one it cannot check. Real authentication happens in [apps/gateway](../../apps/gateway/README.md).
- `econsent.js`: consent normalisation and comprehension-check helpers.
- `accessibility-matcher.js`, exported only as `ui/vitest` (typed via `accessibility-matcher.d.ts`): `toBeAccessible` Vitest matcher built on `axe-core` ([ADR-2537](../../docs/adr/2026-11-22-split-ui-vitest-matcher-and-enforce-demo-bundle-budgets.md)). It is excluded from the root `ui` runtime bundle so `axe-core` never ships in production or demo builds.
- `src/components/`: 23 shared Vue components re-exported from the root `ui` entry (`FileUploadModal`, `MediaPlayer`, `ModalErrorAlert`, `common/EmptyState`, and `clinical/` components `AiActionButton`, `AiSuggestionDrawer`, `AuditLogViewer`, `ClinicalContextBar`, `ClinicalDataTable`, `ClinicalDrawer`, `ClinicalDropzone`, `ClinicalFieldLayout`, `ClinicalFormField`, `ClinicalIconButton`, `ClinicalInput`, `ClinicalLookupInput`, `ClinicalModal`, `ClinicalQueryFlag`, `ClinicalQueryPanel`, `ClinicalRadioGroup`, `ConfidenceBadge`, `PersonaSwitcher`, `SignOutConfirmModal`).
- `src/composables/`: reactive `useFocusTrap(targetRef, options)` (focus containment, LIFO nested overlay stack, background sibling `inert`/`aria-hidden="true"` reconciliation with `[data-focus-trap-exempt="true"]` live-alert exemptions, `Escape` dismissal or lock-screen blocking, and trigger focus restoration), `useEscapeClose(onClose, options)` (LIFO topmost dismissal for non-trapped overlays), `getFocusableElements(container)`, `trapTabFocus(event, container)`, `useAsyncRetry`, and `useSignOutGuard` (flushes debounced drafts and requires explicit confirmation before destructive sign-out cleanup when unsaved work exists), all re-exported from the root `ui` entry. `src/types/cdash.ts`: CDASH types.
- `fonts/`: self-hosted variable `.woff2` subsets for `Inter` (`inter-variable-latin.woff2` with OpenType `cv05`, `cv08`, and `tnum`) and `JetBrains Mono` (`jetbrains-mono-variable-latin.woff2`) plus `OFL.txt`, exported under `./fonts/*` to satisfy `font-src 'self'` CSP policies ([ADR-2823](../../docs/adr/2026-11-22-two-profile-css-tokens-self-hosted-fonts-and-1rem-touch-inputs.md)).
- `tokens.css`, `responsive.css`: centralized light and dark (`[data-theme="dark"]`, `.dark`, `[data-theme="auto"]`) WCAG 2.2 Level AA calibrated semantic design tokens, scalable `rem` typography tokens (`0.75rem` minimum floor), self-hosted `Inter` (`--font-feature-clinical: "cv05" 1, "cv08" 1`) and `JetBrains Mono` (`--font-mono`, `--semantic-font-family-mono`) font families, two-profile surface density and pointer target tokens (`--touch-target-min: 48px` / `--semantic-touch-target-min` per SC 2.5.5, `--control-target-min: 24px` / `--semantic-control-target-min` per SC 2.5.8, `--touch-target-staff: 44px`, `--touch-target-portal: 48px`, `--surface-control-min-height`, `--surface-control-min-width`, `--surface-input-min-height`, `--surface-input-font-size`, `--surface-table-font-size`, `--chrome-height-tablet-max: 52px`), and shared application aliases (`--primary`, `--primary-dark`, `--primary-light`, `--accent`, `--accent-light`, `--accent-bg`, `--text-main`, `--text-muted`, `--bg-main`, `--bg-card`, `--neutral-dark`, `--neutral-light`, `--border`, `--border-control`, `--success`, `--success-bg`, `--warning`, `--warning-bg`, `--error`, `--error-bg`, `--danger`, `--danger-bg`, and `--font`, with color aliases mirrored across dark-theme scopes; semantic text and status tokens delivering `>= 4.5:1` contrast, `--color-border-control` / `--semantic-color-border-control` delivering `>= 3:1` interactive control boundary contrast per SC 1.4.11 while preserving `--semantic-color-border` for passive dividers, a shared low-specificity two-color `:focus-visible` indicator pairing a `2px` `--semantic-color-text-on-solid` inner halo with a `3px` `--semantic-color-accent` outer outline plus `@media (forced-colors: active)` `Highlight` outlines per [ADR-2646](../../docs/adr/2026-11-22-standardize-24px-target-tokens-and-dual-focus-rings.md), wallet gradient tokens `--semantic-color-wallet-start` and `--semantic-color-wallet-end`, viewport-relative drawer width tiers `--drawer-width-sm` [440px], `--drawer-width-md` [480px], `--drawer-width-lg` [640px], `--drawer-width-xl` [920px] and semantic mappings `--semantic-drawer-width-*`, the AI output colour `--semantic-color-ai`, `--semantic-color-ai-bg` and `--semantic-color-ai-border` reserved exclusively for agent output per UX-8 and ADR-2635, global `*` `box-sizing` reset, `.form-actions` layout, `.btn-primary` brand colors, `.sr-only` visually hidden screen-reader utility class, global `font-variant-numeric: tabular-nums` table rules covering all application tables without per-component `<style scoped>` copies per ADR-2650, and global `@media (prefers-reduced-motion: reduce)` rules) and responsive utilities (`[data-surface-profile="staff"]` `44px` touch / `32px–36px` `1280px+` `(pointer: fine)` rules, `[data-surface-profile="portal"]` `48px` rules, `1rem` touch input floor, `.btn-sm` two-profile sizing, legacy `.touch-target` / `.min-touch-target` / `.touch-target-interactive` aliases, plus `.drawer-mobile-full` and `.drawer-panel-mobile-full` for <=640px viewports) (exported as `ui/tokens.css`, `ui/responsive.css`).
- `index.d.ts`: type declarations; `scripts/generate-types.js` runs before the build.

## Scripts

| Command                  | Purpose                                             |
| ------------------------ | --------------------------------------------------- |
| `pnpm --filter ui build` | Generates types, then builds the library with Vite. |
| `pnpm --filter ui test`  | Vitest (`tests/`) with coverage.                    |
| `pnpm --filter ui lint`  | ESLint.                                             |

## Coverage

`pnpm --filter ui test` measures coverage over every source file, components included (ADR-2530). The global thresholds
in `vite.config.js` are a ratchet floor: raise them when coverage rises, never lower them. `signing.js` and
`econsent.js`, the Part 11 signing and eConsent helpers, carry an 80 percent gate of their own.

## Dependencies

- Runtime: peer dependencies `vue` and `lucide-vue-next` (externalized from `dist/`).
- Development: Vite, Vitest with `@vitest/coverage-v8`, `axe-core` (backing `ui/vitest`), TypeScript, `pinia`.

## Used by

[apps/web](../../apps/web/README.md) and [apps/subject-portal](../../apps/subject-portal/README.md) (`"ui": "workspace:*"`). Both apps build it before their own build and test runs.
